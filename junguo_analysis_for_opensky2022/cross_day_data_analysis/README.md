# Cross-Day Data Analysis / 跨日数据分析

## 文件夹概述

本文件夹包含对OpenSky数据集中跨日期航班轨迹存储问题的深入分析。主要研究问题：**跨日期航班轨迹是否真的被存储在两个不同的日期文件中？**

## 🔗 相关项目

**注意**: 本目录与 `../../trajectory_stitching/` 目录功能相关但处于不同阶段：

- **本目录 (cross_day_data_analysis)**: 🔍 **问题分析验证阶段**
  - 目标：证明跨日轨迹分割问题是否存在
  - 方法：统计分析、案例验证、证据收集
  - 结果：提供问题存在的证据和置信度评估

- **trajectory_stitching目录**: 🔧 **问题解决实施阶段**  
  - 目标：实际修复被分割的跨日轨迹
  - 方法：智能检测算法、轨迹拼接、质量控制
  - 结果：生成完整的跨日轨迹数据

**⚠️ 重要更新**: 经过深入重新分析，发现原始分析存在严重缺陷，主要证据案例被证明无效。建议优先参考 `trajectory_stitching` 目录的更严谨的实现方法。

## 🎯 核心结论 (已更新)

**⚠️ 重要修正**: 原始分析结论需要重新评估

**❌ 原始结论**: 跨日期航班轨迹确实被存储在两个不同的日期文件中 (置信度：85%)

**🔍 重新分析发现**:
- 主要证据案例(248757373 vs 248777023)被证明是两架不同飞机的记录
- 分析方法存在严重缺陷，匹配标准不够严谨
- 未充分考虑替代假设和飞行物理约束
- **调整后置信度**: 0% (结论基本不可信)

**💡 建议**: 
1. 问题可能存在，但需要更严格的验证方法

## 📊 明确证据

### 1. 强证据 ⭐⭐⭐⭐⭐
- **文件时间重叠**: 相邻数据文件存在约14小时的时间重叠
  - `2022-01-01.parquet` 包含到 `2022-01-02 14:14:23` 的数据
  - `2022-01-02.parquet` 从 `2022-01-02 00:25:23` 开始
- **文件内容跨日**: 每个文件都包含超过24小时的数据，证明文件确实跨越多个日期

### 2. 中等证据 ⭐⭐⭐
- **跨日航班匹配**: 找到了具体的跨日航班匹配案例
  - 例如：飞机248757373在两个文件中都有记录，时间间隔37.5分钟，距离20.2公里
- **飞行参数连续性**: 匹配案例显示了合理的高度、速度变化

## 脚本功能分析 / Script Function Analysis

### 1. analyze_cross_midnight.py
- **功能**: 分析跨午夜时间的航班轨迹匹配
- **方法**: 基于时间和位置连续性匹配晚间和凌晨的航班
- **输出**: 找到14个潜在的跨日期航班匹配案例

### 2. detailed_evidence_analysis.py
- **功能**: 详细验证具体的跨日航班案例
- **方法**: 分析飞行参数连续性，包括时间、位置、高度、速度
- **结果**: 验证了1个高可信度的跨日轨迹案例

### 3. file_boundary_analysis.py
- **功能**: 分析数据文件的时间边界和分割逻辑
- **发现**: 
  - 文件间存在大量时间重叠（约14小时）
  - 文件命名与内容日期存在差异
  - 证明了数据不是严格按日期分割

### 4. logic_analysis_and_conclusions.py
- **功能**: 详细解释分析逻辑和假设，识别潜在逻辑漏洞
- **内容**: 
  - 分析方法论解释
  - 潜在问题识别（如ICAO24重用）
  - 证据强度评估
  - 最终结论总结

### 5. analyze_flight_id_processing.py  
- **功能**: 分析flight_id的处理逻辑和跨日期问题
- **重点**: 研究flight_id在不同日期文件中的分布

### 6. analyze_overlap.py
- **功能**: 分析相邻日期文件之间的数据重叠
- **方法**: 检查时间戳重叠和飞机标识符重复

### 7. analyze_time_gaps.py
- **功能**: 分析轨迹中的时间间隔和连续性
- **目标**: 识别可能的轨迹断裂点

## 🔍 分析方法论

### 1. 数据文件结构分析
- 检查文件命名规律和时间范围
- 发现文件按日期命名但内容跨日

### 2. 时间边界检查
- 分析相邻文件的时间重叠
- 证明数据不是严格按日期分割

### 3. 跨日航班匹配算法
- **时间连续性**: 时间间隔 < 60分钟
- **空间连续性**: 距离 < 100公里
- **飞行参数连续性**: 高度、速度变化合理

### 4. 具体案例验证
- 详细分析匹配案例的飞行参数
- 验证时间、位置、高度、速度的合理性

## ⚠️ 潜在限制

1. **ICAO24标识符可能重用** - 通过时间和位置连续性验证缓解
2. **数据时间戳精度问题** - 使用UTC时间和合理阈值缓解
3. **GPS坐标误差** - 使用大圆距离计算和合理距离阈值缓解
4. **数据完整性** - 可能存在数据丢失或延迟
