# 高质量与完美轨迹数据集生成指南

本文系统说明以下两个数据集的生成流程、参数与可复现命令：

- complete_high_quality_trajectories：对“高质量航班”进行掐头去尾与插值后的完整可用数据集。
- perfect_trajectories：在 complete 基础上剔除任意关键列仍有 NaN 的整条航班，确保 100% 无缺失。

## 前置准备
- 环境：`conda activate opensky`
- 原始输入：`opensky_2024_PRC_dataset/rawtrajectories/*.parquet`
- 过滤输出：`opensky_2024_PRC_dataset/classic_filtered_trajectories/*.parquet`
- 可选分析源（平滑+限洞插值 20s）：`opensky_2024_PRC_dataset/classic__1e-2_interpolated_trajectories/*.parquet`

## 总体流程
1) 过滤（不插值，仅置 NaN）→ 2) 可选平滑插值供分析 → 3) 质量分析 → 4) 高质量ID → 5) 生成 complete → 6) 生成 perfect → 7) 可选跳变巡检

## 1. 过滤（经典链）
- 脚本：`filter_trajs.py`（顺序：FilterCstLatLon → FilterCstPosition → FilterCstSpeed → MyFilterDerivative → FilterIsolated）
- 仅置 NaN，不做插值；使用真实时间差 Δt。
- 示例（按日文件）：
```
python filter_trajs.py \
  -t_in opensky_2024_PRC_dataset/rawtrajectories/2022-01-01.parquet \
  -t_out opensky_2024_PRC_dataset/classic_filtered_trajectories/2022-01-01.parquet \
  -strategy classic
```

## 2. 可选：平滑+限洞插值（供质量分析）
- 脚本：`interpolate.py`（csaps 三次样条；最大洞宽 20s 限制，不跨大缺口）
- 示例：
```
python interpolate.py \
  -t_in opensky_2024_PRC_dataset/classic_filtered_trajectories/2022-01-01.parquet \
  -t_out opensky_2024_PRC_dataset/classic__1e-2_interpolated_trajectories/2022-01-01.parquet \
  -smooth 1e-2
```

## 3. 质量分析（按航班统计缺失率与最长缺失窗口）
- 脚本：`junguo_analysis_for_opensky2022/analysis_for_interpolation/All_trajectory_NaN_analysis.py`
- 输入建议：`classic__1e-2_interpolated_trajectories`（更接近最终可用度）
- 示例：
```
python junguo_analysis_for_opensky2022/analysis_for_interpolation/All_trajectory_NaN_analysis.py \
  --data_dir opensky_2024_PRC_dataset/classic__1e-2_interpolated_trajectories \
  --output_dir junguo_analysis_for_opensky2022/analysis_for_interpolation/quick_analysis_output \
  --sample_percentage 1.0 --max_workers 40
```

## 4. 高质量 ID 提取
- 脚本：`junguo_analysis_for_opensky2022/analysis_for_interpolation/get_high_quality_trajectories_id.py`
- 输出：`high_quality_flight_ids.txt`（默认以经纬度综合缺失率 ≤ 5%）
- 示例：
```
python junguo_analysis_for_opensky2022/analysis_for_interpolation/get_high_quality_trajectories_id.py
```

## 5. 生成 complete_high_quality_trajectories
- 脚本：`junguo_analysis_for_opensky2022/analysis_for_interpolation/regenerate_complete_dataset.py`
- 输入：`opensky_2024_PRC_dataset/classic_filtered_trajectories`
- 处理：
  - 掐头去尾：按经纬有效范围截取（移除开头/结尾 NaN 区间）。
  - 插值：
    - 经纬/高度/速度：线性插值（双向补全）。
    - 航迹角：复数插值法处理 0/360° 连续性。
- 输出：`complete_high_quality_trajectories/complete_YYYY-MM-DD.parquet`
- 示例：
```
python junguo_analysis_for_opensky2022/analysis_for_interpolation/regenerate_complete_dataset.py
```

## 6. 生成 perfect_trajectories（确保 0 缺失）
- 脚本：`analysis/implement_final_solution.py`
- 输入：`complete_high_quality_trajectories/*.parquet`
- 动作：剔除任一关键列仍有 NaN 的整条航班，写出到 `perfect_trajectories/`
- 示例：
```
python analysis/implement_final_solution.py
```

## 7. 可选：perfect 集跳变巡检
- 脚本：`analysis/detect_perfect_jumps.py`
- 作用：从“100% 无缺失”的角度再筛出“短时跨远距离”的可疑跳变段，便于后续重插值或剔除。
- 示例：
```
python analysis/detect_perfect_jumps.py \
  --data-dir perfect_trajectories \
  --out-dir reports/jump_reports
```

## 参数与阈值（参考）
- 滤波链：`filterclassic.py` 中各阈值（MyFilterDerivative 的 first/second；孤立点 20s 等）。
- 平滑插值：`interpolate.py` 的 `smooth` 与 `MAX_HOLE_SIZE=20s`。
- 高质量筛选：`get_high_quality_trajectories_id.py` 默认以经纬度综合缺失率 ≤ 5%（可在脚本中调整）。
- 最终 0 缺失：`analysis/implement_final_solution.py` 的关键列列表可按需扩展或收缩。

## 性能与并行建议
- 机器为 HDD，建议分批处理与适度并发：
  - 分析与生成阶段的多进程默认已做保守上限（通常 ≤ CPU 一半）。
  - 可根据 I/O 实际情况在命令行参数或脚本处调整 `max_workers`/`processes`。

## 常见问题
- Track 角度插值：`regenerate_complete_dataset.py` 使用复数插值避免 0/360° 跳变。
- 垂直速度全 NaN：最终 perfect 阶段会整体剔除该航班（保证 0 缺失）。
- 巡检与再处理：jump 巡检结果仅提供清单，后续重插值/截断/剔除需业务判断并同步更新记录。
