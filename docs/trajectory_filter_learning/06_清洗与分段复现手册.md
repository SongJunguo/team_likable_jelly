# 数据清洗与分段复现手册（v2 限洞 inside）

本文记录“过滤 → 重建 complete（仅内部洞 + 20s 限洞）→ 切段（0 NaN 连续片段）→ 跳变/NaN 巡检”的一键复现实操，方便后续复跑与排错。

## 环境与约定
- 环境：`conda activate opensky`
- 时区：全流程使用 UTC（可视化可换本地时区但不影响处理）
- 数据根：`/workspace/aircraft_trajectory/team_likable_jelly/opensky_2024_PRC_dataset`
- 机器：HDD，建议并发 6–8，避免 I/O 抖动

目录约定（关键输入/输出）
- 输入（已存在）：
  - `opensky_2024_PRC_dataset/rawtrajectories/`（原始）
  - `opensky_2024_PRC_dataset/classic_filtered_trajectories/`（过滤后，不插值）
  - `high_quality_flight_ids.txt`（高质量航班ID列表）
- 本轮输出（v2）：
  - `opensky_2024_PRC_dataset/complete_high_quality_trajectories__v2_lim20s_inside/`
  - `opensky_2024_PRC_dataset/segmented_trajectories_v2_lim20s_inside/`
  - `reports/jump_reports_segmented_v2/`
  - `junguo_analysis_for_opensky2022/analysis_for_interpolation/quick_analysis_output_segmented_v2/`

## 0.（可选）获取高质量航班ID
- 基于样条“限洞插值”结果进行缺失率分析后生成 ID 列表：
```
python junguo_analysis_for_opensky2022/analysis_for_interpolation/All_trajectory_NaN_analysis.py   --data_dir opensky_2024_PRC_dataset/classic__1e-2_interpolated_trajectories   --output_dir junguo_analysis_for_opensky2022/analysis_for_interpolation/quick_analysis_output   --sample_percentage 1.0 --max_workers 40
python junguo_analysis_for_opensky2022/analysis_for_interpolation/get_high_quality_trajectories_id.py
```
- 产物：`high_quality_flight_ids.txt`

## 1.（若缺失）过滤 raw → classic_filtered（只置 NaN，不插值）
- 单日示例：
```
python filter_trajs.py   -t_in opensky_2024_PRC_dataset/rawtrajectories/2022-01-01.parquet   -t_out opensky_2024_PRC_dataset/classic_filtered_trajectories/2022-01-01.parquet   -strategy classic
```

## 2. 重建 complete（v2：仅内部洞 + 20s 限洞）
- 脚本：`junguo_analysis_for_opensky2022/analysis_for_interpolation/regenerate_complete_all.sh`
- 默认参数已指向 v2 输出目录；直接运行：
```
bash junguo_analysis_for_opensky2022/analysis_for_interpolation/regenerate_complete_all.sh
```
- 说明：
  - 不覆盖旧目录；每日输出 `complete_YYYY-MM-DD.parquet`
  - 采用 `limit_area='inside'` 禁止头尾外推；`MAX_HOLE_SIZE=20s` 不跨大洞桥接

## 3. 切段（0 NaN 连续片段）
- 脚本：`junguo_analysis_for_opensky2022/analysis_for_interpolation/split_segments_all.sh`
- 默认规则：必需列 `latitude longitude altitude` 非 NaN；`Δt ≤ 20s`；`min_points=30`；`min_duration=120s`
```
bash junguo_analysis_for_opensky2022/analysis_for_interpolation/split_segments_all.sh
```
- 命名：
  - `original_flight_id`：原始 ID；`segment_index`：1..N
  - 新 `flight_id = original_flight_id * 10000 + segment_index`（int64）
  - `flight_seg_info = "{original}_s{index}_{startUTC}_{endUTC}"`

## 4. 跳变检测（多进程）
- 脚本：`analysis/detect_perfect_jumps.py`（已支持并行）
```
python analysis/detect_perfect_jumps.py   --data-dir opensky_2024_PRC_dataset/segmented_trajectories_v2_lim20s_inside   --out-dir reports/jump_reports_segmented_v2   --procs 8 --from 2022-01-01 --to 2022-12-31
```
- 输出：
  - 每日：`perfect_jumps_YYYY-MM-DD.csv`、`perfect_jumps_summary_YYYY-MM-DD.csv`
  - 合并：`jump_events_all.csv`、`jump_events_summary.csv`

## 5. NaN 巡检（逐分段航班汇总）
```
python junguo_analysis_for_opensky2022/analysis_for_interpolation/All_trajectory_NAN_analysis.py   --data_dir opensky_2024_PRC_dataset/segmented_trajectories_v2_lim20s_inside   --output_dir junguo_analysis_for_opensky2022/analysis_for_interpolation/quick_analysis_output_segmented_v2   --sample_percentage 1.0 --max_workers 40
```
- 产物：每“分段后的 flight_id”对应的各列缺失率、最长缺失窗口等统计。

## 6. 常见问题与排错
- Parquet 读取异常（pyarrow）：
  - 临时绕过：`pd.read_parquet(path, engine="pyarrow", use_legacy_dataset=True)`
  - 低层 API：`pyarrow.parquet.read_table(path).to_pandas()`
- 斜坡/延伸：
  - v2 已禁用头尾外推、限制 20s 大洞；仍见斜坡，多半是绘图连线（中间无行），不影响底层数据。
- 并发与 I/O：
  - HDD 上建议并发 6–8；若 I/O 等待高，降低 `--procs`。
- 时间：
  - 全流程 UTC；图上的东八区仅用于展示。

## 7. TL;DR（一键串行）
```
# 1) 重建 complete v2（不覆盖旧目录）
bash junguo_analysis_for_opensky2022/analysis_for_interpolation/regenerate_complete_all.sh

# 2) 切段（0 NaN 连续片段）
bash junguo_analysis_for_opensky2022/analysis_for_interpolation/split_segments_all.sh

# 3) 跳变检测（并行）
python analysis/detect_perfect_jumps.py   --data-dir opensky_2024_PRC_dataset/segmented_trajectories_v2_lim20s_inside   --out-dir reports/jump_reports_segmented_v2   --procs 8 --from 2022-01-01 --to 2022-12-31

# 4) NaN 巡检（全量）
python junguo_analysis_for_opensky2022/analysis_for_interpolation/All_trajectory_NaN_analysis.py   --data_dir opensky_2024_PRC_dataset/segmented_trajectories_v2_lim20s_inside   --output_dir junguo_analysis_for_opensky2022/analysis_for_interpolation/quick_analysis_output_segmented_v2   --sample_percentage 1.0 --max_workers 40
```
