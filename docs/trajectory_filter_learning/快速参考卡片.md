## 二、过滤器配置速查

### 2.1 过滤器链（默认配置）

```python
from filterclassic import (
    FilterCstLatLon,
    FilterCstPosition,
    FilterCstSpeed,
    MyFilterDerivative,
    FilterIsolated,
)

# 经典过滤器链（classic策略）
filter_chain = (
    FilterCstLatLon()      # 1️⃣ 经纬度重复检测
    | FilterCstPosition()  # 2️⃣ 三维位置重复检测
    | FilterCstSpeed()     # 3️⃣ 速度重复检测
    | MyFilterDerivative() # 4️⃣ 导数异常检测
    | FilterIsolated()     # 5️⃣ 孤立点检测
)
```

## 三、数据统计常用代码

### 3.1 查看过滤效果

```python
import pandas as pd

# 加载数据
df_raw = pd.read_parquet('rawtrajectories/2022-01-01.parquet')
df_filtered = pd.read_parquet('filtered_trajectories/2022-01-01.parquet')

# 统计NaN变化
print("=== NaN统计 ===")
for col in ['latitude', 'longitude', 'altitude', 'groundspeed', 'vertical_rate']:
    nan_before = df_raw[col].isna().sum()
    nan_after = df_filtered[col].isna().sum()
    new_nans = nan_after - nan_before
    pct = 100 * new_nans / len(df_raw)
    print(f"{col:15s}: {nan_before:8d} → {nan_after:8d} (+{new_nans:6d}, {pct:5.2f}%)")

# 总体统计
total_before = df_raw.isna().sum().sum()
total_after = df_filtered.isna().sum().sum()
print(f"\n总NaN数: {total_before} → {total_after} (+{total_after - total_before})")

# 数据保留率
n_cells = len(df_filtered) * len(df_filtered.columns)
retention = 1 - total_after / n_cells
print(f"数据保留率: {retention*100:.2f}%")
```

### 3.3 导数分布分析

```python
import numpy as np

# 计算高度一阶导数
df_sorted = df_raw.sort_values(['flight_id', 'timestamp'])
timediff = df_sorted.groupby('flight_id')['timestamp'].diff().dt.total_seconds()
alt_diff = df_sorted.groupby('flight_id')['altitude'].diff()
deriv1 = np.abs(alt_diff / timediff)

# 统计分布
print("高度一阶导数分布:")
print(f"  50th percentile: {deriv1.quantile(0.50):.2f} ft/s")
print(f"  95th percentile: {deriv1.quantile(0.95):.2f} ft/s")
print(f"  99th percentile: {deriv1.quantile(0.99):.2f} ft/s")
print(f"  99.9th percentile: {deriv1.quantile(0.999):.2f} ft/s")
print(f"  当前阈值: 200 ft/s")

# 绘制直方图
import matplotlib.pyplot as plt
plt.figure(figsize=(10, 6))
plt.hist(deriv1.dropna().clip(0, 500), bins=100, edgecolor='black', alpha=0.7)
plt.axvline(x=200, color='r', linestyle='--', label='Current threshold (200)')
plt.xlabel('Altitude derivative (ft/s)')
plt.ylabel('Count')
plt.title('Distribution of Altitude First Derivative')
plt.legend()
plt.grid(True)
plt.show()
```

## 四、故障排查速查表

### 4.1 常见错误及解决

| 错误信息 | 原因 | 解决方法 |
|---------|------|---------|
| `AssertionError in checktime()` | 时间未严格递增 | 执行去重和排序：<br>`df = df.drop_duplicates(['flight_id', 'timestamp'])`<br>`.sort_values(['flight_id', 'timestamp'])` |
| `KeyError: 'altitude'` | 缺少必要列 | 检查输入文件是否完整 |
| `MemoryError` | 内存不足 | 减少并行进程数或分块处理 |
| `NaN率超过30%` | 阈值过严或数据质量差 | 放宽导数阈值或检查原始数据 |
| 处理速度慢 | 单线程或I/O瓶颈 | 使用`-j`并行或优化I/O |

### 4.2 性能优化检查清单

- [ ] 使用并行处理：`make cleantrajectories -j8`
- [ ] 检查磁盘I/O是否是瓶颈（机械硬盘 vs 固态硬盘）
- [ ] 验证内存是否充足（峰值约10-15GB/进程）
- [ ] 使用PyArrow引擎：`pd.read_parquet(..., engine='pyarrow')`
- [ ] 减少调试输出和中间文件写入

### 4.3 数据质量检查清单

- [ ] 原始数据是否有重复记录？
- [ ] 时间戳是否严格递增？
- [ ] 必要字段（lat, lon, alt）是否都存在？
- [ ] 数值范围是否合理（如高度-1200~60000 ft）？
- [ ] 采样率是否一致（大部分应为1秒）？

## 六、参数调优速查

### 6.1 推荐调整步骤

1. **先统计原始数据**
   ```python
   # 计算导数分布
   deriv1_stats = deriv1.describe(percentiles=[0.9, 0.95, 0.99, 0.999])
   print(deriv1_stats)
   ```

2. **设置初始阈值**
   - 一阶导：99-99.5百分位
   - 二阶导：95-99百分位

3. **测试并评估**
   ```python
   # 测试不同阈值
   thresholds = [150, 200, 250, 300]
   for thresh in thresholds:
       filter_deriv = MyFilterDerivative(altitude=dict(first=thresh, second=thresh/4))
       df_filtered = filter_deriv.apply(df.copy())
       nan_count = df_filtered['altitude'].isna().sum()
       print(f"Threshold {thresh}: {nan_count} NaNs")
   ```

4. **可视化验证**
   - 查看被屏蔽的点是否合理
   - 确认没有误杀正常爬升/下降

### 6.2 典型场景推荐阈值

| 场景 | altitude一阶 | altitude二阶 | 说明 |
|------|-------------|-------------|------|
| **严格模式** | 150 | 40 | 高质量数据，容忍度低 |
| **默认模式** | 200 | 50 | 平衡准确率和召回率 |
| **宽松模式** | 300 | 75 | 数据质量一般，避免误杀 |
| **直升机** | 100 | 25 | 允许悬停和急速机动 |
