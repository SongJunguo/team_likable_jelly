## 二、案例1：重复广播问题

### 2.1 问题描述

ADS-B设备在某些情况下会重复发送相同的位置数据，导致轨迹中出现"静止点"。

### 2.2 原始数据

```python
import pandas as pd
import numpy as np

# 模拟重复广播
data = pd.DataFrame({
    'flight_id': [12345] * 10,
    'timestamp': pd.date_range('2022-01-01 10:00:00', periods=10, freq='1s'),
    'latitude': [39.9042, 39.9042, 39.9042, 39.9042, 39.9100,  # 前4个重复
                 39.9150, 39.9200, 39.9250, 39.9300, 39.9350],
    'longitude': [116.4074, 116.4074, 116.4074, 116.4074, 116.4100,
                  116.4150, 116.4200, 116.4250, 116.4300, 116.4350],
    'altitude': [1000, 1020, 1040, 1060, 1080,
                 1100, 1120, 1140, 1160, 1180]
})

print("原始数据:")
print(data[['timestamp', 'latitude', 'longitude', 'altitude']])
```

**输出**：
```
             timestamp  latitude  longitude  altitude
0  2022-01-01 10:00:00   39.9042   116.4074      1000
1  2022-01-01 10:00:01   39.9042   116.4074      1020  ← 经纬度重复
2  2022-01-01 10:00:02   39.9042   116.4074      1040  ← 经纬度重复
3  2022-01-01 10:00:03   39.9042   116.4074      1060  ← 经纬度重复
4  2022-01-01 10:00:04   39.9100   116.4100      1080
5  2022-01-01 10:00:05   39.9150   116.4150      1100
...
```

### 2.3 应用FilterCstLatLon

```python
from filterclassic import FilterCstLatLon

print("\n应用FilterCstLatLon后:")
print(data_filtered[['timestamp', 'latitude', 'longitude', 'altitude']])
```

**输出**：
```
             timestamp  latitude  longitude  altitude
0  2022-01-01 10:00:00   39.9042   116.4074      1000  ← 保留第一个
1  2022-01-01 10:00:01       NaN        NaN      1020  ← 屏蔽
2  2022-01-01 10:00:02       NaN        NaN      1040  ← 屏蔽
3  2022-01-01 10:00:03       NaN        NaN      1060  ← 屏蔽
4  2022-01-01 10:00:04   39.9100   116.4100      1080  ← 位置变化，保留
5  2022-01-01 10:00:05   39.9150   116.4150      1100

```

## 三、案例2：高度突刺

```python
# 计算一阶导数

    print(f"  {i}: {d:.1f}{marker}")
```

**输出**：
```

  2: 20.0
  3: 1460.0 ⚠️  ← 超过阈值(200)

  6: 20.0
```

```python
# 计算二阶导数
```

## 四、案例3：孤立点问题

### 4.1 问题描述

由于信号丢失或其他原因，轨迹中出现孤立的观测点，与前后观测相距较远。

### 4.2 原始数据

```python
# 模拟孤立点
timestamps = []
altitudes = []

# 正常段1 (0-3秒)
for i in range(4):
    timestamps.append(pd.Timestamp('2022-01-01 10:00:00') + pd.Timedelta(seconds=i))
    altitudes.append(1000 + i * 20)

# 孤立点 (25秒，远离前后观测)
timestamps.append(pd.Timestamp('2022-01-01 10:00:25'))
altitudes.append(1500)

# 正常段2 (50-53秒)
for i in range(50, 54):
    timestamps.append(pd.Timestamp('2022-01-01 10:00:00') + pd.Timedelta(seconds=i))
    altitudes.append(2000 + (i - 50) * 20)

data = pd.DataFrame({
    'flight_id': [12345] * len(timestamps),
    'timestamp': timestamps,
    'latitude': np.linspace(39.9042, 39.9500, len(timestamps)),
    'longitude': np.linspace(116.4074, 116.4500, len(timestamps)),
    'altitude': altitudes,
})

print("原始数据:")
print(data[['timestamp', 'altitude']])
```

**输出**：
```
             timestamp  altitude
0  2022-01-01 10:00:00      1000
1  2022-01-01 10:00:01      1020
2  2022-01-01 10:00:02      1040
3  2022-01-01 10:00:03      1060
4  2022-01-01 10:00:25      1500  ← 孤立点（距前22s，距后25s）
5  2022-01-01 10:00:50      2000
6  2022-01-01 10:00:51      2020
7  2022-01-01 10:00:52      2040
8  2022-01-01 10:00:53      2060
```

### 4.3 计算洞宽

```python
from filterclassic import compute_holes

# 转换时间为秒
t = (data['timestamp'] - data['timestamp'].iloc[0]).dt.total_seconds().values

for i, (ts, alt, d) in enumerate(zip(data['timestamp'], data['altitude'], dt)):

    print(f"  {i}: {ts} | alt={alt} | dt={d:.1f}s{marker}")
```

```
  3: 2022-01-01 10:00:03 | alt=1060 | dt=1.0s
```

## 五、案例4：完整过滤流程

### 5.1 复杂场景

构造一个包含多种异常的复杂轨迹：
- 重复广播（索引1-3）
- 高度突刺（索引7）
- 速度未更新（索引10-12）
- 孤立点（索引15）

### 5.2 生成数据

```python
# 构造复杂场景
np.random.seed(42)

n = 20
data = pd.DataFrame({
    'flight_id': [12345] * n,
    'timestamp': pd.date_range('2022-01-01 10:00:00', periods=n, freq='1s'),
    'latitude': [39.9042] * 4 + list(np.linspace(39.9042, 39.9500, n-4)),  # 前4个重复
    'longitude': [116.4074] * 4 + list(np.linspace(116.4074, 116.4500, n-4)),
    'altitude': [1000 + i*20 for i in range(n)],
    'vertical_rate': [200] * n,
    'groundspeed': [250] * n,
    'track': [90] * n,
})

# 添加高度突刺
data.loc[7, 'altitude'] = 2500

# 添加速度未更新
data.loc[10:12, 'vertical_rate'] = data.loc[9, 'vertical_rate']
data.loc[10:12, 'groundspeed'] = data.loc[9, 'groundspeed']
data.loc[10:12, 'track'] = data.loc[9, 'track']

# 添加孤立点（删除周围观测）
data = data.drop(index=[14, 16])
data = data.reset_index(drop=True)

print("原始数据 (前10行):")
print(data.head(10)[['timestamp', 'latitude', 'longitude', 'altitude']])
```

### 5.3 逐步应用过滤器

```python
from filterclassic import *

# 原始统计
print("\n=== 原始数据统计 ===")
print(f"总行数: {len(data)}")

# Step 2: FilterCstPosition
df2 = FilterCstPosition().apply(df1)
print("\n=== 2. FilterCstPosition ===")
print(f"新增NaN: {df2.isna().sum().sum() - df1.isna().sum().sum()}")

# Step 3: FilterCstSpeed
df3 = FilterCstSpeed().apply(df2)
print("\n=== 3. FilterCstSpeed ===")
print(f"新增NaN: {df3.isna().sum().sum() - df2.isna().sum().sum()}")

# Step 4: MyFilterDerivative
df4 = MyFilterDerivative().apply(df3)
print("\n=== 4. MyFilterDerivative ===")
print(f"新增NaN: {df4.isna().sum().sum() - df3.isna().sum().sum()}")

df5 = FilterIsolated().apply(df4)
print("\n=== 5. FilterIsolated ===")
print(f"新增NaN: {df5.isna().sum().sum() - df4.isna().sum().sum()}")

print("\n=== 最终统计 ===")
print(f"总NaN数量: {df5.isna().sum().sum()}")
print(f"数据保留率: {(1 - df5.isna().sum().sum() / (len(df5) * len(df5.columns))) * 100:.1f}%")
```

## 六、案例5：航迹角unwrap

### 6.1 问题描述

航迹角在0°和360°之间循环，导致虚假跳变。

### 6.2 原始数据

```python
# 模拟航迹角跨越0/360度
data = pd.DataFrame({
    'flight_id': [12345] * 10,
    'timestamp': pd.date_range('2022-01-01 10:00:00', periods=10, freq='1s'),
    'latitude': np.linspace(39.9042, 39.9500, 10),
    'longitude': np.linspace(116.4074, 116.4500, 10),
    'altitude': np.linspace(1000, 1180, 10),
    'track': [350, 355, 0, 5, 10, 15, 20, 25, 30, 35],
    #                    ↑ 从355到0，实际变化+5°，但差值-355°
    'vertical_rate': [200] * 10,
    'groundspeed': [250] * 10,
})

print("原始航迹角:")
print(data[['timestamp', 'track']])
```

### 6.3 计算导数（不unwrap）

```python
# 不使用unwrap
track_diff = np.abs(data['track'].diff().values[1:])
timediff = data['timestamp'].diff().dt.total_seconds().values[1:]
deriv_no_unwrap = track_diff / timediff

print("\n一阶导数（未unwrap）:")
for i, d in enumerate(deriv_no_unwrap, start=1):
    marker = " ⚠️" if d > 12 else ""
    print(f"  {i}: {d:.1f}°/s{marker}")
```

**输出**：
```
一阶导数（未unwrap）:
  1: 5.0°/s
  2: 355.0°/s ⚠️  ← 虚假跳变！
  3: 5.0°/s
  4: 5.0°/s
...
```

### 6.4 计算导数（unwrap）

```python
# 使用unwrap
track_unwrapped = np.unwrap(data['track'].values, period=360)
track_diff_unwrap = np.abs(track_unwrapped[1:] - track_unwrapped[:-1])
deriv_unwrap = track_diff_unwrap / timediff

print("\n航迹角unwrap前后对比:")
print("Index  Original  Unwrapped")
for i, (orig, unw) in enumerate(zip(data['track'], track_unwrapped)):
    print(f"  {i}     {orig:3.0f}°      {unw:3.0f}°")

print("\n一阶导数（unwrap后）:")
for i, d in enumerate(deriv_unwrap, start=1):
    marker = " ⚠️" if d > 12 else ""
    print(f"  {i}: {d:.1f}°/s{marker}")
```

**输出**：
```
航迹角unwrap前后对比:
Index  Original  Unwrapped
  0     350°      350°
  1     355°      355°
  2       0°      360°  ← 转换为连续值
  3       5°      365°
  4      10°      370°
...

一阶导数（unwrap后）:
  1: 5.0°/s
  2: 5.0°/s  ← 正确识别为小变化
  3: 5.0°/s
  4: 5.0°/s
...
```

## 七、性能分析

### 7.1 单个文件处理时间

```python
import time
from traffic.core import Traffic

# 加载真实数据
df = pd.read_parquet('rawtrajectories/2022-01-01.parquet')
print(f"数据量: {len(df)} 行, {len(df['flight_id'].unique())} 个航班")

# 构建过滤器链
filter_chain = (
    FilterCstLatLon()
    | FilterCstPosition()
    | FilterCstSpeed()
    | MyFilterDerivative()
    | FilterIsolated()
)

# 计时
start_time = time.time()
df_filtered = (
    Traffic(df)
    .filter(filter=filter_chain, strategy=nointerpolate)
    .eval(max_workers=1)
    .data
)
end_time = time.time()

print(f"\n处理时间: {end_time - start_time:.2f} 秒")
print(f"吞吐量: {len(df) / (end_time - start_time):.0f} 行/秒")
```

### 7.2 各过滤器耗时占比

```python
import time

def time_filter(df, filter_obj, name):
    """计时单个过滤器"""
    start = time.time()
    df_out = filter_obj.apply(df.copy())
    duration = time.time() - start
    print(f"{name}: {duration:.2f}s ({duration/total_time*100:.1f}%)")
    return df_out, duration

# 测试
```

### 8.2 检查过滤效果

```python
# 1. 各变量的NaN增长
for col in ['latitude', 'longitude', 'altitude', 'groundspeed']:
    nan_before = df[col].isna().sum()
    nan_after = df_filtered[col].isna().sum()
    new_nans = nan_after - nan_before
    print(f"{col}: +{new_nans} NaNs ({100*new_nans/len(df):.2f}%)")

# 2. 过滤是否过于激进？
total_nans = df_filtered.isna().sum().sum()
total_cells = len(df_filtered) * len(df_filtered.columns)
nan_rate = total_nans / total_cells
print(f"\n总NaN率: {nan_rate*100:.2f}%")
if nan_rate > 0.3:
    print("⚠️ 警告: NaN率超过30%，可能过滤过于激进")
```
