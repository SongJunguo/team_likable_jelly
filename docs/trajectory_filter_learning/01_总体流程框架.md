# 轨迹过滤系统 - 总体流程框架

## 一、系统概述

轨迹过滤系统是数据清洗流程的核心环节，负责将原始ADS-B轨迹数据中的异常观测点识别并屏蔽（置为NaN），为后续的插值和特征提取提供干净的数据基础。

**核心设计理念**：
- **只屏蔽，不插值**：在过滤阶段仅将异常数据置为NaN，不进行任何形式的数据插值
- **组合式设计**：使用多个独立的过滤器，通过管道（Pipeline）串联
- **渐进式清理**：按照数据质量问题的层级，从简单到复杂逐步过滤

## 四、关键技术特征

### 4.1 过滤器组合设计

使用管道操作符 `|` 实现链式过滤：

```python
filter_chain = (
    FilterCstLatLon()      # 经纬度常数检查
    | FilterCstPosition()  # 位置常数检查
    | FilterCstSpeed()     # 速度常数检查
    | MyFilterDerivative() # 导数异常检查（见“极简上手”笔记本：learn_python/myfilterderivative_quickstart.ipynb）
    |
    | 产出数据集构建（详见：docs/trajectory_filter_learning/05_高质量与完美数据集生成.md）
    | FilterIsolated()     # 孤立点检查
)
```

**优势**：
- 模块化：每个过滤器独立实现，易于测试和维护
- 可扩展：新增过滤器只需继承`FilterBase`并实现`apply`方法
- 可配置：通过调整过滤器顺序和参数适应不同场景

### 4.2 无插值策略

在过滤阶段显式禁用插值：

```python
Traffic(df).filter(
    filter=filter_chain,
    strategy=nointerpolate  # 恒等函数，禁用内置插值
).eval(max_workers=1)
```

**原因**：
- 避免将错误数据插值到有效轨迹中
- 保证过滤结果的纯净性
- 将插值延后到专门的插值阶段（interpolate.py），可控地进行"限洞插值"

### 4.3 真实时间差计算

所有基于时间的判断都使用真实的时间戳差值，而非假设固定采样率：

```python
timediff = (
    data.loc[valid_mask, 'timestamp']
    .diff()
    .dt.total_seconds()
    .values[1:]
)
```

**好处**：
- 适应不规则采样（OpenSky数据虽然99.9%为1秒，但仍有变化）
- 避免在采样率突变处误判

## 五、过滤器执行顺序的设计考量

### 为什么是这个顺序？

1. **FilterCstLatLon** (第一步)
   - 处理最明显的重复广播问题
   - 为后续位置相关的过滤器清理输入

2. **FilterCstPosition** (第二步)
   - 在经纬度清理基础上，增加高度维度检查
   - 三维位置整体静止时才屏蔽，更严格

3. **FilterCstSpeed** (第三步)
   - 处理速度相关的重复广播
   - 与位置过滤互补，形成完整的"静态检测"

4. **MyFilterDerivative** (第四步)
   - 在静态噪声清理后，检测动态突变
   - 需要前序过滤器先移除重复点，避免零导数干扰

5. **FilterIsolated** (第五步)
   - 最后清理孤立点
   - 在其他异常清理完成后，孤立点判定更准确

## 六、关键参数汇总

| 参数名称 | 数值 | 所在模块 | 用途 |
|---------|------|---------|------|
| **孤立点阈值** | 20秒 | `FilterIsolated` | 与其他有效观测相距≥20s的点被置NaN |
| **最大洞宽** | 20秒 | `interpolate.py` | 后续插值时，≥20s的缺口不插值 |
| **altitude 一阶导** | 200 ft/s | `MyFilterDerivative` | 高度变化速率阈值 |
| **altitude 二阶导** | 50 ft/s² | `MyFilterDerivative` | 高度变化加速度阈值 |
| **vertical_rate 一阶导** | 1500 (ft/min)/s | `MyFilterDerivative` | 垂直速度变化阈值 |
| **groundspeed 一阶导** | 12 kt/s | `MyFilterDerivative` | 地面速度变化阈值 |
| **lat/lon 一阶导** | 0.01 deg/s | `MyFilterDerivative` | 经纬度变化速率阈值 |
| **lat/lon 二阶导** | 0.06 deg/s² | `MyFilterDerivative` | 经纬度变化加速度阈值 |

## 七、执行方式

### 7.1 单文件处理

```bash
python filter_trajs.py \
    -t_in opensky_2024_PRC_dataset/rawtrajectories/2022-01-01.parquet \
    -t_out filtered_trajectories/2022-01-01.parquet \
    -strategy classic
```

### 7.2 批量处理（通过Makefile）

```bash
# 过滤所有日度文件（支持多进程并行）
make cleantrajectories -j4  # 使用4个并行进程
```

Makefile会自动：
- 遍历所有日度文件
- 创建输出目录
- 并行执行过滤任务
- 记录日志

## 九、后续流程

过滤完成后的数据将进入：

1. **插值阶段**（interpolate.py）
   - 三次平滑样条插值
   - 限洞插值（≤20秒的缺口）
   - 计算派生变量（速度、能量率等）

2. **特征提取**
   - 爬升特征（feature_climbing.py）
   - 巡航特征（feature_cruise_infos.py）
   - 风效应特征（feature_wind_effect.py）
   - 天气特征（feature_weather_from_metars.py）

3. **模型训练**（regression.py）
   - LightGBM训练
   - 交叉验证
   - 预测TOW
