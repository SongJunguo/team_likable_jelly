# 过滤器模块详解 - filterclassic.py

## 一、模块概述

`filterclassic.py` 实现了5个独立的过滤器，每个过滤器针对特定类型的数据质量问题。所有过滤器都继承自`traffic.algorithms.filters.FilterBase`，可以通过管道操作符串联。

**文件位置**：`/workspace/aircraft_trajectory/team_likable_jelly/filterclassic.py`

**核心理念**：
- **只屏蔽，不插值**：将异常观测置为NaN
- **独立性**：每个过滤器可独立测试和配置
- **渐进性**：从简单到复杂，逐层清理

## 二、辅助函数详解

### 2.1 checktime() - 时间序列验证

```python
def checktime(df: pd.DataFrame) -> None:
    """验证 timestamp 是否严格递增。"""
    t = df.timestamp.values
    assert (t[1:] > t[:-1]).all()
```

**功能**：
- 检查时间戳是否严格递增（无重复、无倒退）
- 如果发现非递增，抛出`AssertionError`

**使用场景**：
- 在过滤器内部用于调试
- 确保输入数据已正确排序

**为什么需要严格递增？**
- 所有差分和导数计算都假设时间递增
- 时间倒退会导致负的时间差，破坏计算逻辑

### 2.2 isvar() - 变化检测函数

```python
def isvar(v: np.ndarray) -> np.ndarray:
    """判断相邻采样是否发生变化。

    - 自动忽略任何一端为 NaN 的比较
    - 返回长度为 len(v) - 1 的布尔数组
    """
    isnotnan = ~np.isnan(v)
    # 仅在两侧都非 NaN 的位置比较数值
    diffnotnan = np.logical_and(isnotnan[1:], isnotnan[:-1])
    diff = v[1:] != v[:-1]
    return np.logical_and(diff, diffnotnan)
```

**功能**：
- 判断相邻元素是否不同
- 自动跳过NaN值的比较

**示例**：
```python
v = np.array([1.0, 1.0, 2.0, np.nan, 2.0, 3.0])
isvar(v)
# 输出：[False, True, False, False, True]
#       ↑     ↑     ↑      ↑      ↑
#       1=1   1≠2   2~NaN  NaN~2  2≠3
```

**关键设计**：
- `isnotnan[1:] & isnotnan[:-1]`：两端都非NaN才比较
- 避免`NaN != NaN`被误判为变化

### 2.3 compute_holes() - 洞宽计算函数

```python
def compute_holes(t: np.ndarray, inans: np.ndarray) -> np.ndarray:
    """计算每个采样点与最近有效观测之间的最小时间差。

    inans: 布尔掩码，True表示当前位置为NaN
    """
    tnan = t.copy()
    tnan[inans] = np.nan  # 将NaN位置的时间戳清空

    # 前向/后向填充得到最近有效时间
    tf = pd.DataFrame({"tf": tnan}, dtype=np.float64).ffill().values[:, 0]
    tb = pd.DataFrame({"tb": tnan}, dtype=np.float64).bfill().values[:, 0]

    # 初始化为大值
    dt = 10000.0 * np.ones(tnan.shape[0], dtype=np.float64)

    # 计算到最近未来和过去有效点的时间差
    dt[:-1] = np.minimum(dt[:-1], tb[1:] - tnan[:-1])
    dt[1:] = np.minimum(dt[1:], tnan[1:] - tf[:-1])

    return dt
```

**功能**：
- 对每个时刻，计算它与最近有效观测的时间差
- 用于判定孤立点（时间差过大的点）

**算法流程**：

```
原始时间序列：  [t0, t1, t2, t3, t4, t5]
变量有效性：    [OK, NaN, NaN, OK, NaN, OK]

前向填充(ffill)：[t0, t0, t0, t3, t3, t5]  ← 每个点看到的"上一个有效时间"
后向填充(bfill)：[t0, t3, t3, t3, t5, t5]  ← 每个点看到的"下一个有效时间"

对于t2 (NaN):
  - 距离上一个有效点：t2 - t0
  - 距离下一个有效点：t3 - t2
  - 取最小值作为dt[2]
```

**为什么需要这个函数？**
- 识别孤立点：dt过大的点没有足够的邻居支撑
- 避免"长桥接"插值：孤立点不应该参与插值

## 三、过滤器详解

### 3.1 FilterCstLatLon - 经纬度重复检测

```python
class FilterCstLatLon(filters.FilterBase):
    """检测经纬度重复广播的滤波器。"""

    def apply(self, df: pd.DataFrame) -> pd.DataFrame:
        df = df.copy()
        lat = df.latitude.values
        lon = df.longitude.values
        isupdated = np.zeros(lat.shape, dtype=bool)

        # 任何一项变化即视为"更新过"
        isupdated[1:] = np.logical_or(isvar(lat), isvar(lon))

        # 对未更新的行清空经纬度
        df.loc[np.logical_not(isupdated), ["latitude", "longitude"]] = np.nan
        return df
```

**检测逻辑**：
1. 判断相邻时刻的经纬度是否变化
2. 如果经度和纬度都未变化 → 标记为"未更新"
3. 将未更新的行的经纬度置为NaN

**为什么这样做？**
- ADS-B设备可能重复广播相同的位置
- 静止的飞机（地面等待）位置确实不变
- 飞行中的飞机位置不变通常是异常

**示例**：
```python
# 输入数据
timestamp    latitude  longitude
10:00:00     39.9042   116.4074  ← 北京机场
10:00:01     39.9042   116.4074  ← 重复
10:00:02     39.9042   116.4074  ← 重复
10:00:03     39.9100   116.4100  ← 正常飞行

# 过滤后
timestamp    latitude  longitude
10:00:00     39.9042   116.4074  ← 保留第一个
10:00:01     NaN       NaN       ← 屏蔽
10:00:02     NaN       NaN       ← 屏蔽
10:00:03     39.9100   116.4100  ← 保留
```

**注意事项**：
- 第一个点总是保留（`isupdated[1:]`从索引1开始）
- 只要经度或纬度有一个变化就保留

### 3.2 FilterCstPosition - 三维位置重复检测

```python
class FilterCstPosition(filters.FilterBase):
    """若高度与经纬度三者均未更新，则清空当前行。"""

    def apply(self, df: pd.DataFrame) -> pd.DataFrame:
        df = df.copy()
        if df.shape[0] <= 1:
            return df

        alt = df.altitude.values
        lat = df.latitude.values
        lon = df.longitude.values
        isupdated = np.zeros(alt.shape, dtype=bool)

        # 只要高度或经纬度发生变化，就视为更新
        isupdated[1:] = np.logical_or(isvar(alt), isvar(lat))
        isupdated[1:] = np.logical_or(isupdated[1:], isvar(lon))

        df.loc[
            np.logical_not(isupdated),
            ["latitude", "longitude", "altitude"]
        ] = np.nan
        return df
```

**与FilterCstLatLon的区别**：
- `FilterCstLatLon`：只检查经纬度
- `FilterCstPosition`：检查经纬度+高度

**使用场景**：
- 飞机在地面等待：经纬度不变，高度也不变（正常）
- 飞机爬升中静止：三维位置都不变（异常）

**过滤策略**：
- 三个维度都不变 → 置NaN
- 任何一个维度变化 → 保留

**示例**：
```python
# 输入数据
timestamp    latitude  longitude  altitude
10:00:00     39.9042   116.4074   1000
10:00:01     39.9042   116.4074   1000  ← 三维都不变
10:00:02     39.9042   116.4074   1500  ← 高度变化
10:00:03     39.9100   116.4100   1500  ← 位置变化

# 过滤后
timestamp    latitude  longitude  altitude
10:00:00     39.9042   116.4074   1000
10:00:01     NaN       NaN        NaN    ← 屏蔽
10:00:02     39.9042   116.4074   1500
10:00:03     39.9100   116.4100   1500
```

### 3.3 FilterCstSpeed - 速度重复检测

```python
class FilterCstSpeed(filters.FilterBase):
    """若速度相关指标全部未更新，则清空对应列。"""

    def apply(self, df: pd.DataFrame) -> pd.DataFrame:
        df = df.copy()
        if df.shape[0] <= 1:
            return df

        vrate = df.vertical_rate.values
        track = df.track.values
        gs = df.groundspeed.values
        isupdated = np.zeros(vrate.shape, dtype=bool)

        # 任意项变化即可
        isupdated[1:] = np.logical_or(isvar(vrate), isvar(gs))
        isupdated[1:] = np.logical_or(isupdated[1:], isvar(track))

        df.loc[
            np.logical_not(isupdated),
            ["vertical_rate", "track", "groundspeed"]
        ] = np.nan
        return df
```

**检测的三个速度指标**：
1. `vertical_rate`：垂直速度（ft/min）
2. `groundspeed`：地面速度（kt）
3. `track`：航迹角（度）

**为什么需要这个过滤器？**
- 位置可能更新，但速度未更新（传感器延迟）
- 速度全部不变通常意味着数据未刷新

**与位置过滤器的关系**：
- 互补关系：位置正常但速度异常，或反之
- 串联使用：形成完整的"静态检测"体系

### 3.4 MyFilterDerivative - 导数异常检测（核心）

这是最复杂也最重要的过滤器，基于一阶和二阶导数检测"突刺点"。

#### 配置参数

```python
class MyFilterDerivative(filters.FilterBase):
    # 默认阈值配置
    default: ClassVar[dict[str, DerivativeParams]] = dict(
        altitude=dict(first=200, second=50),
        geoaltitude=dict(first=200, second=150),
        vertical_rate=dict(first=1500, second=1000),
        groundspeed=dict(first=12, second=10),
        track=dict(first=12, second=10),
        latitude=dict(first=0.01, second=0.06),
        longitude=dict(first=0.01, second=0.06),
    )
```

**参数含义**：
- `first`：一阶导数阈值（变化速率）
- `second`：二阶导数阈值（变化加速度）

**单位对应**：
- `altitude`：ft/s（英尺每秒）
- `vertical_rate`：(ft/min)/s（垂直速度的变化率）
- `groundspeed`：kt/s（节每秒）
- `latitude/longitude`：度/秒
- `track`：度/秒

#### 核心算法

```python
def apply(self, data: pd.DataFrame) -> pd.DataFrame:
    if data.shape[0] <= 2:
        return data

    for column, params in self.columns.items():
        if column not in data.columns:
            continue

        nanmask = np.isnan(data[column].values)
        index = data.index[np.logical_not(nanmask)]
        val = data[column].values[np.logical_not(nanmask)]

        # 1. 计算真实时间差
        timediff = (
            data.loc[np.logical_not(nanmask), self.time_column]
            .diff()
            .dt.total_seconds()
            .values[1:]
        )

        # 2. 航迹角特殊处理
        if column == "track":
            val = np.unwrap(val, period=360)

        # 3. 计算一阶和二阶差分
        diff1val = val[1:] - val[:-1]
        diff1 = np.abs(diff1val)
        diff2 = np.abs(diff1val[1:] - diff1val[:-1])

        # 4. 计算导数
        deriv1 = diff1 / timediff
        deriv2 = 2 * diff2 / (timediff[1:] + timediff[:-1])

        # 5. 二阶导投票
        spikea = deriv2 >= params["second"]
        killa = np.zeros(val.shape[0])
        killa[:-2] += spikea  # i-1
        killa[1:-1] += spikea  # i
        killa[2:] += spikea  # i+1

        # 6. 一阶导投票
        spikev = deriv1 >= params["first"]
        killv = np.zeros(val.shape[0])
        killv[:-1] += spikev  # i-1
        killv[1:] += spikev   # i

        # 7. 票数≥2的点置NaN
        data.loc[index[np.logical_or(killa >= 2, killv >= 2)], column] = np.nan

    return data
```

#### 算法步骤详解

**步骤1：计算真实时间差**

```python
timediff = (
    data.loc[valid_mask, 'timestamp']
    .diff()
    .dt.total_seconds()
    .values[1:]
)
```

- 不假设固定采样率
- 使用真实的时间戳差值（秒）
- 忽略NaN点，只在有效点之间计算

**步骤2：航迹角预处理**

```python
if column == "track":
    val = np.unwrap(val, period=360)
```

**为什么需要unwrap？**
```
原始航迹角：  [350°, 355°, 0°, 5°, 10°]
                             ↑
                         虚假跳变-355°

unwrap后：    [350°, 355°, 360°, 365°, 370°]
                             ↑
                         真实变化+5°
```

**步骤3-4：计算导数**

```python
# 一阶导数（变化率）
deriv1[i] = |x[i] - x[i-1]| / Δt[i]

# 二阶导数（变化加速度）
deriv2[i] = 2 * |(x[i] - x[i-1]) - (x[i-1] - x[i-2])| / (Δt[i] + Δt[i-1])
```

**物理意义**：
- 一阶导：速度（变化快慢）
- 二阶导：加速度（速度的变化）

**示例**：高度突刺
```
时间(s)   高度(ft)   一阶导(ft/s)   二阶导(ft/s²)
0         1000       -              -
1         1020       20             -
2         1500       480 ⚠️        460 ⚠️⚠️
3         1040       -460 ⚠️       940 ⚠️⚠️
4         1060       20             480 ⚠️⚠️
5         1080       20             0
```

**步骤5-6：投票机制**

**二阶导投票**（三点窗口）：
```python
killa[i-1] += 1
killa[i]   += 1
killa[i+1] += 1
```

**为什么影响三个点？**
- 二阶导异常意味着中间点附近有尖锐转折
- 转折可能在i-1、i或i+1处
- 保守策略：三个都标记

**一阶导投票**（两点窗口）：
```python
killv[i-1] += 1
killv[i]   += 1
```

**为什么影响两个点？**
- 一阶导异常意味着i-1到i之间跳变过大
- 可能是i-1错误，也可能是i错误
- 两个都标记

**步骤7：判决**

```python
# 分别计票、分别判定：
(二阶票 >= 2) 或 (一阶票 >= 2) → 置 NaN
```

说明：不是将一阶与二阶的票数相加再判定，而是分别判断任一类票数是否达到2。

**为什么是2票？**
- **太低（1票）**：误杀率高（一次触发就屏蔽）
- **太高（3票）**：漏杀率高（需要多次触发）
- **2票**：平衡准确率和召回率

#### 投票机制示例

```
索引   高度   一阶导  二阶导  一阶票  二阶票  总票数  结果
0     1000    -       -       0      0      0      保留
1     1020    OK      -       0      0      0      保留
2     1500    ⚠️     ⚠️     1+1    1+1+1   5      屏蔽
3     1040    ⚠️     ⚠️     1+1    1+1+1   5      屏蔽
4     1060    OK      ⚠️     0      1+1+1   3      屏蔽
5     1080    OK      OK      0      0      0      保留
```

**说明**：
- 索引2、3明确异常（一阶和二阶都超阈值）→ 票数5
- 索引4虽然一阶正常，但二阶仍超阈值 → 票数3
- 投票机制确保异常点及其邻居都被清理

### 3.5 FilterIsolated - 孤立点检测

```python
class FilterIsolated(filters.FilterBase):
    """剔除与其它观测相距 20 秒以上的孤立点。"""

    def apply(self, df: pd.DataFrame) -> pd.DataFrame:
        df = df.copy()
        lvar = [x for x in list(df)
                if x not in ["timestamp", "icao24", "flight_id"]]

        # 转换时间为秒
        df["t"] = (
            (df.timestamp - df.timestamp.iloc[0])
            / pd.to_timedelta(1, unit="s")
        ).values.astype(np.float64)

        for v in lvar:
            dt = compute_holes(df["t"], np.isnan(df[v].values))
            # 超过 20 秒即判定为孤立观测
            df[v] = df[v].mask(dt > 20)
            # 无法计算的情况同时屏蔽
            df[v] = df[v].mask(np.isnan(dt))

        return df.drop(columns=["t"])
```

**检测逻辑**：
1. 对每个变量，计算每个点与最近有效观测的时间差`dt`
2. 如果`dt > 20秒` → 判定为孤立点 → 置NaN
3. 如果`dt`无法计算（首尾点） → 也置NaN

**为什么要去除孤立点？**
- 孤立点缺乏邻居支撑
- 插值会导致"长桥接"（跨大缺口插值）
- 孤立点本身可靠性存疑

**示例**：

```
时间(s)  高度(ft)  dt(s)   判定
0       1000      N/A     孤立（首点）
1       1020      1       正常
2       1040      1       正常
3       1060      1       正常
25      1500      22      孤立（>20s）
26      1520      1       正常
50      2000      24      孤立（>20s）
```

**20秒阈值的选择**：
- 与插值阶段的"最大洞宽"(20秒)一致
- 确保插值只在有效支撑区间进行
- 经验值：基于ADS-B采样特性

## 四、过滤器链设计原则

### 4.1 执行顺序

```python
filter_chain = (
    FilterCstLatLon()      # 1️⃣
    | FilterCstPosition()  # 2️⃣
    | FilterCstSpeed()     # 3️⃣
    | MyFilterDerivative() # 4️⃣
    | FilterIsolated()     # 5️⃣
)
```

**顺序的重要性**：

1. **先清理静态异常** (1-3)
   - 重复广播是最简单的异常
   - 清理后避免干扰导数计算

2. **再检测动态异常** (4)
   - 导数需要干净的输入
   - 重复点会导致零导数

3. **最后清理孤立点** (5)
   - 需要前序过滤后的"有效点分布"
   - 判定孤立性更准确

### 4.2 过滤器独立性

每个过滤器都应该：
- **幂等性**：多次应用结果相同
- **可交换性**：同类过滤器顺序可调整
- **无副作用**：只修改数据，不依赖全局状态

### 4.3 可扩展性

**添加新过滤器**：

```python
class FilterAltitudeRange(filters.FilterBase):
    """过滤超出合理高度范围的点。"""

    def __init__(self, min_alt=-1000, max_alt=60000):
        self.min_alt = min_alt
        self.max_alt = max_alt

    def apply(self, df: pd.DataFrame) -> pd.DataFrame:
        df = df.copy()
        mask = (df.altitude < self.min_alt) | (df.altitude > self.max_alt)
        df.loc[mask, 'altitude'] = np.nan
        return df

# 使用
filter_chain = (
    FilterAltitudeRange(min_alt=0, max_alt=50000)  # 新过滤器
    | FilterCstLatLon()
    | FilterCstPosition()
    | FilterCstSpeed()
    | MyFilterDerivative()
    | FilterIsolated()
)
```

```python
plt.show()
```

3. **权衡**：
   - **阈值太低**：误杀正常快速爬升/下降
   - **阈值太高**：漏掉明显的异常跳变

### 5.2 孤立点阈值调整

```python
class FilterIsolated(filters.FilterBase):
    def __init__(self, threshold=20):
        self.threshold = threshold
```

## 六、性能优化

### 6.1 向量化操作

**好的做法**（向量化）：
```python
isupdated[1:] = np.logical_or(isvar(lat), isvar(lon))
```

**差的做法**（循环）：
```python
for i in range(1, len(lat)):
    if lat[i] != lat[i-1] or lon[i] != lon[i-1]:
        isupdated[i] = True
```

**性能差异**：向量化比循环快10-100倍

### 6.2 内存优化


### 7.3 记录过滤统计

```python
def log_filter_stats(df_before, df_after, filter_name):
    """记录过滤器的统计信息。"""
    print(f"\n{filter_name}:")
    print(f"  Input rows: {len(df_before)}")
    print(f"  Output rows: {len(df_after)}")

    for col in df_before.columns:
        if col in ['timestamp', 'flight_id', 'icao24']:
            continue
        nan_before = df_before[col].isna().sum()
        nan_after = df_after[col].isna().sum()
        new_nans = nan_after - nan_before
        if new_nans > 0:
            print(f"  {col}: +{new_nans} NaNs "
                  f"({100*new_nans/len(df_before):.2f}%)")
```

## 八、常见问题

### Q1：为什么过滤后NaN增加了很多？

**A**：这是正常的。过滤器的目的就是将异常点置为NaN。如果NaN增加过多（>20%），可能需要：
- 检查阈值是否过于严格
- 检查原始数据质量
- 可视化查看哪些点被屏蔽了

### Q2：导数阈值如何确定？

**A**：默认阈值来自经验，但应该根据实际数据调整：
1. 统计实际导数的分布
2. 选择99-99.9百分位作为阈值
3. 可视化验证阈值合理性

### Q3：过滤器顺序可以改变吗？

**A**：部分可以，但建议保持：
- 静态过滤器(1-3)可以调整顺序
- 导数过滤器(4)必须在静态过滤后
- 孤立点过滤器(5)必须最后

### Q4：如何处理特殊场景（如直升机）？

**A**：创建专门的过滤器配置：
```python
# 直升机配置：允许悬停（位置不变）
helicopter_filter = (
    FilterCstSpeed()       # 只检查速度，不检查位置
    | MyFilterDerivative(
        altitude=dict(first=100, second=25)  # 更宽松的阈值
    )
    | FilterIsolated()
)
```
