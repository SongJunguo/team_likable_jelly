# 短簇剔除与两阶段筛选方案（滑窗 + 密度/聚类）

本文将“短小突刺/短小漂移簇”的定位与处理方案沉淀为可复现规范，用于补强现有过滤链在边界处的“1–2 点残留”问题。方案既可在过滤链中落地（FilterShortBurst），也可在分段之后做 post‑clean（生成 segmented_v3）。

## 背景与问题
- 已有链路：`FilterCstLatLon → FilterCstPosition → FilterCstSpeed → MyFilterDerivative → FilterIsolated`。
- 问题现象：异常块的首端常残留 1–2 个点（票数累计不到“≥2票”），尾端则被剔除；Δt 通常 < 20s，`FilterIsolated` 不触发。
- 完整/分段策略：complete v2（仅内部洞、限 20s，不外推）+ segmented_v2（Δt≤20s、必需列 0 NaN）已避免跨大洞，但“短簇”仍需额外清理。

## 设计目标
- 消除被 NaN 包夹或突然偏离邻域趋势的“短小异常簇”（长度 ≤ 2 或 ≤ 3）。
- 与现链路互补：尽量不误杀正常边界、不引入跨大洞连线。
- 可控计算量：对 12k 点的长段采用滑窗/两阶段筛选，分钟级完成，多进程并行。

## 放置位置
- 推荐 A：过滤链内（MyFilterDerivative 之后、FilterIsolated 之前）新增 `FilterShortBurst`。
- 可选 B：分段后 post‑clean（在 `segmented_v2` 上生成 `segmented_v3`），零侵入、快速见效。

## 距离与特征度量
- 水平距离 d_xy：Haversine（km）或 ENU 投影后平面欧氏（km）。
- 垂直分量 d_z：|Δalt| 换算为 km，并以权重 α 合入（推荐 α≈0.7，≈700 m 高差等效 1 km 水平）。
- 时间分量 d_t（可选）：|Δt| 换算为“等效位移” β·Δt（km），β≈0.2–0.3 km/s（≈720–1080 km/h）。
- 统一距离（欧氏）：`D = sqrt(dx² + dy² + (α·dz_km)² + (β·Δt)²)`；在窗口/段内使用统一维度，避免混维度。

> 注意：若在过滤链阶段高度缺失较多，主聚类用 2D XY；高度作为“垂直复核”门（有则用，无则跳过），避免“少一维→距离变短”的偏差。

## 两阶段筛选（轻筛 + 精筛）
- 轻筛（O(N)）：用动力学阈值标记“可疑种子”，降低后续开窗次数。
  - 速度：`v(i) ≥ max(v_abs, ratio_v·median_v_window)`，建议 `v_abs=1000 km/h`，`ratio_v=3`。
  - 加速度：`a(i) ≥ max(a_abs, ratio_a·median_a_window)`，建议 `a_abs=15–20 m/s²`，`ratio_a=5`。
  - 基线：滑窗（如 60s）中位数 + MAD（稳健估计），Δt 用真实时间差。
- 精筛（对种子 ±30–45s 小窗）：
  - 选项 1：DBSCAN（推荐）
    - 特征：ENU(km) + α·alt_km（可选）+ β·Δt（可选），`metric='euclidean'`。
    - 参数：
      - 空中：`eps=1.0 km`, `min_samples=3`；地面：`eps=0.2–0.5 km`。
      - 短簇门：簇长度 `≤ L_short`（2 或 3）→ 整簇置 NaN。
  - 选项 2：半径密度法（更轻量）
    - 对 i：计算最近邻距离 `dmin(i)` 与半径内邻居数 `countR(i)`；
    - 判 `dmin>R_km` 且 `countR<N_min`（如 `R_km=3–5`, `N_min=3`）为异常；与“短簇门”结合。
- 垂直复核（仅在高度可用时）
  - 对候选异常/短簇，应用 `|Δalt| ≥ max(z_abs, ratio_z·MAD_z)`（如 `z_abs=300–500 m`, `ratio_z=3–5`）；对不满足的可回收。

## 与现链路的协同
- 票数机制先干掉“大突刺”；短簇剔除清理“1–2 点残留”；`FilterIsolated` 最后扫时间上孤立点。
- complete v2 的“仅内部洞 + 20s 限洞”与 segmented_v2 的“Δt≤20s、0 NaN”保证了小窗动力学/密度判定的稳定性。

## 参数建议（起步）
- 窗口：`T_w=60s`，步长 `20–30s`；种子精筛小窗 `±45s`。
- DBSCAN：空中 `eps=1.0 km`，地面 `eps=0.3 km`，`min_samples=3`；`L_short=2`。
- 权重：`α≈0.7`（700 m≈1 km），`β≈0.25 km/s`（≈900 km/h）。
- 密度法：`R_km=5`，`N_min=3`。
- 轻筛阈值：`v_abs=1000 km/h, ratio_v=3；a_abs=15–20 m/s², ratio_a=5`。

## 实施路径
- 路径 A（过滤链内）
  1) 在 `filterclassic.py` 新增 `FilterShortBurst`：
     - 主依据：2D XY 聚类/密度 + 短簇门；
     - 有高度时附加“垂直复核”；
     - 命中后对 `latitude/longitude` 置 NaN，并联动 `altitude/groundspeed/track`。
  2) 串联位置：`… → MyFilterDerivative → FilterShortBurst → FilterIsolated`。
  3) 文档：在 `03_过滤器模块详解.md` 与 `06_清洗与分段复现手册.md` 补充说明与默认参数。
- 路径 B（分段后 post‑clean）
  1) 新增 `post_segment_short_burst_clean.py`（多进程），输入 `segmented_v2`，输出 `segmented_v3`；
  2) 对每段执行“轻筛 + 精筛 + 短簇门”，必要时拆段、重排 `segment_index/flight_id`；
  3) 在 `06_清洗与分段复现手册.md` 增加一节操作指引。

## 计算量与并行
- 12k 点长段整段 DBSCAN 不划算；滑窗/两阶段后复杂度近似 `O(窗口数 × n_window log n_window)`。
- 你机器 80 核 + HDD：并行按“日/航班/段”分配，I/O 为主要瓶颈；建议并发 6–8。

## 误杀控制与回退
- 仅删除 `L_short`（≤2/3）的短簇；保守时可同时要求超阈速度/加速度或空间/时间隔离门（`dmin>5km` 或 `Δt_gap≥60s`）。
- 保留“白名单相位/阶段”选项（如起飞/进近的强机动段可适度放宽）。

## 验证与回归
- 点名样例：
  - 2022‑03‑06 flight_id=249935181：04:04 窗口首端短簇应清理；
  - 2022‑11‑22 flight_id=257192918：03:04 窗口短簇应清理。
- 指标：
  - 段内 `max(Δt)` 仍 ≤ 20s；必需列 NaN=0；
  - 删除点数占比、被删短簇长度分布；
  - 跳变检测事件变化与可视化对比。
